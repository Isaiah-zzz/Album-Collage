# Album Collage Generator

A React-based web application that creates beautiful, AI-powered collages from your Spotify music albums. The app integrates with Spotify's API to fetch album artwork and uses AI algorithms to generate aesthetically pleasing layouts and visual effects.

## Features

- **Spotify Integration**: Connect to your Spotify account to fetch album artwork and metadata
- **AI-Powered Layout Generation**: Uses golden ratio principles and AI algorithms to create visually appealing collage layouts
- **Interactive Editing**: Drag and drop interface for manual album positioning and resizing
- **Visual Effects**: Multiple visual effect options including clean, vintage, and artistic styles
- **AI Image Generation**: Integration with Hugging Face's Stable Diffusion models for AI-generated collage backgrounds
- **Color Analysis**: Smart color palette extraction and matching from album artwork
- **Responsive Design**: Built with Tailwind CSS for modern, responsive UI

## Tech Stack

- **Frontend**: React 18 with React Router
- **Styling**: Tailwind CSS with Material Tailwind components
- **AI Services**: Hugging Face Inference API (Stable Diffusion)
- **Music API**: Spotify Web API
- **Layout Engine**: Custom AI layout algorithms with golden ratio optimization

## Usage

1. **Connect to Spotify**: The app will automatically authenticate with Spotify using client credentials
2. **Browse Albums**: Use the random album selector or search for specific albums
3. **Create Collage**: Navigate to the "Make Collage" page to start creating
4. **Customize Layout**: Choose from AI-generated layouts or manually arrange albums
5. **Apply Effects**: Select visual effects to enhance your collage
6. **Generate AI Background**: Optionally use AI to generate custom backgrounds
7. **Export**: Download your finished collage
